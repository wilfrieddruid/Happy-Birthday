# Site d'anniversaire interactif (Communauté)

Ceci est un bundle de code pour le site d'anniversaire interactif (Communauté). Le projet original est disponible à l'adresse https://www.figma.com/design/batTqVQXfjUDUUbPV8JOsP/Interactive-Birthday-Site--Community-.

## Lancer le code

Exécutez `npm i` pour installer les dépendances.

Exécutez `npm run dev` pour démarrer le serveur de développement.

Exécutez `npm run build` pour générer la version de production.
