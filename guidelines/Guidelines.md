## Bouton
Le composant Bouton est un élément interactif fondamental de notre système de design, conçu pour déclencher des actions ou guider
les utilisateurs dans l'application. Il fournit un retour visuel et des indications claires pour améliorer l'expérience utilisateur.

### Utilisation
Les boutons doivent être utilisés pour les actions importantes que les utilisateurs doivent effectuer, telles que la soumission de formulaires, la confirmation de choix,
ou le lancement de processus. Ils communiquent l'interactivité et doivent porter des libellés clairs et orientés vers l'action.

### Variantes
* Bouton principal
  * Objectif : Utilisé pour l'action principale d'une section ou d'une page
  * Style visuel : Gras, rempli avec la couleur principale de la marque
  * Utilisation : Un seul bouton principal par section pour guider les utilisateurs vers l'action la plus importante
* Bouton secondaire
  * Objectif : Utilisé pour les actions alternatives ou de soutien
  * Style visuel : Contouré avec la couleur principale, fond transparent
  * Utilisation : Peut apparaître à côté d'un bouton principal pour les actions moins importantes
* Bouton tertiaire
  * Objectif : Utilisé pour les actions les moins importantes
  * Style visuel : Texte seul, sans bordure, avec la couleur principale
  * Utilisation : Pour les actions qui doivent être disponibles sans être mises en avant
